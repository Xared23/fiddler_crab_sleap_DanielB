# Coding Principles

The following instructions should always be followed when writing code.

## Instructions

When you are asked to complete a coding task, it is important that your solution/implementation is as
faithful as possible to the user's request. Importantly, do NOT ever alter code that is unrelated to the direct request.
Assume that the rest of the codebase in which you are working is not to be touched, even if you come across something
that looks like it needs improvement. If you come across something that you think needs to be changed in the codebase
that is not related to the user's request, you will mention this to the user and ask for explicit instructions as to how to proceed rather than make any changes without user consent. Always write code in a clean way that anticipates the fact that you are working with a living codebase whose functionalities will be extended upon. 
When working within a Project Folder, make sure to familiarize yourself with that project's scripts and src--essentially its overall functionality. This is to get a conceptual idea of what you are working with.
